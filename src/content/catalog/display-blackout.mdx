## What it does

Blacks out every display except the one you choose, so a single screen stays lit
while you focus. Launch it from the terminal, then press **1**, **2**, or **3** to
pick the screen to keep — the rest go dark until you dismiss it.

## Install & run

```bash
git clone https://github.com/kyle-lesinger/display-blackout
cd display-blackout
swift run
```

Single-file Swift/AppKit tool — no dependencies beyond the macOS SDK.

## When to reach for it

- Screen-sharing or recording one monitor and want the others out of frame.
- Killing visual distractions on secondary displays during deep work.
