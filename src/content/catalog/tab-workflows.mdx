## What it does

Defines named "workspaces" — sets of browser tabs laid out across multiple
monitors — that you open with a single command. It's the personal `pm` workspace
launcher, generalized so anyone can declare their own tab sets.

## Install & run

```bash
git clone https://github.com/kyle-lesinger/tab-workflows
# source the script from your ~/.zshrc, then:
tabflow <workspace-name>
```

See the repo README for defining workspaces and granting the required macOS
Automation permissions.

## When to reach for it

- Spinning up the same multi-monitor browser layout at the start of every workday.
- Context-switching between projects, each with its own set of tabs/dashboards.
