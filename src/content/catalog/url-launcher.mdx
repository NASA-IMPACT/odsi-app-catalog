## What it does

Shows a URL bar on whichever display you invoke it from. Type a URL and it opens
Chrome on that **same** screen — handy on multi-monitor setups where new browser
windows otherwise land on the wrong display.

## Install & run

```bash
git clone https://github.com/kyle-lesinger/url-launcher
cd url-launcher
swift run
```

Single-file Swift/AppKit tool — no dependencies beyond the macOS SDK.

## When to reach for it

- Multi-monitor workflows where you want the browser to open where you're looking.
- A fast keyboard-driven "open this link here" without dragging windows around.
